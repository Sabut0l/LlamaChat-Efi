Злобыч - кастомная модель на 200M параметров с контекстным окном на 1024.
Задумывался как агент, с которым можно пообщаться, пошутить. По характеру он классический токсик, грубиан, который не блещит умом. 
Модель задумывалась как постироная над классическими AI агентами. 

Данная модель является экспериментом и предназначена только для развлекательных целей.
